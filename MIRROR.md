# Akeeba Backup CORE for WordPress

An unofficial mirror of the vendor's releases, so the plugin can be installed with Composer:

    "repositories": [{ "type": "vcs", "url": "https://github.com/trevorbicewebdesign/akeebabackupwp.git" }],
    "require": { "trevorbicewebdesign/akeebabackupwp": "*" }

Each tag is one release, as downloaded from the vendor, unchanged except for this file and
`composer.json` (the vendor's own, if any, is kept as `composer.vendor.json`). Not
affiliated with or supported by the vendor. Published with
`release-plugin-mirror.sh` from the WordPress test kit.
